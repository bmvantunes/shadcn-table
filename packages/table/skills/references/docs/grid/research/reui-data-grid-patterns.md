# ReUI data-grid patterns

## Status and scope

This note records implementation references from ReUI's public Base UI data-grid source at immutable commit [`14185b983e9049ac6786e0f69a764bb3ba70a2b5`](https://github.com/keenthemes/reui/tree/14185b983e9049ac6786e0f69a764bb3ba70a2b5). ReUI is an MIT-licensed pattern source, not a BrunoTable dependency or public API model.

Use these references to accelerate visual and renderer work while preserving BrunoTable's settled identity, state-ownership, continuous-row-space, exact-value, and safety contracts. Verify every borrowed detail against the installed TanStack Table v9 source under `.repos/table` and the relevant BrunoTable ADR before implementation.

## Borrow

## Do not copy

| ReUI pattern                                                                                                                                                                                                                                                 | Why it is incompatible with BrunoTable                                                                                                                                         |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Public `table` prop, TanStack `Column`/`Table` objects, or broad Data Grid context from [`data-grid.tsx`](https://github.com/keenthemes/reui/blob/14185b983e9049ac6786e0f69a764bb3ba70a2b5/registry-reui/bases/base/reui/data-grid/data-grid.tsx)            | TanStack remains opaque. BrunoTable-owned controls use typed capability commands and narrow projections; arbitrary toolbar children receive no table controller.               |
| A `tableLayout` boolean bag from [`data-grid.tsx`](https://github.com/keenthemes/reui/blob/14185b983e9049ac6786e0f69a764bb3ba70a2b5/registry-reui/bases/base/reui/data-grid/data-grid.tsx)                                                                   | Capabilities are strict and compositional. Do not add page-style `show...` or renderer-mode props that create unsupported combinations.                                        |
| Registered pagination, page-size UI, or append-only `onFetchMore` from [`data-grid-table-virtual.tsx`](https://github.com/keenthemes/reui/blob/14185b983e9049ac6786e0f69a764bb3ba70a2b5/registry-reui/bases/base/reui/data-grid/data-grid-table-virtual.tsx) | Both BrunoTable variants expose one Continuous Row Space. Server rows use sparse authoritative indexes and Query Generations, not an appended array.                           |
| Row index as a fallback key in [`data-grid-table-virtual.tsx`](https://github.com/keenthemes/reui/blob/14185b983e9049ac6786e0f69a764bb3ba70a2b5/registry-reui/bases/base/reui/data-grid/data-grid-table-virtual.tsx)                                         | Row positions are never identity. Client identity comes from `getRowId`; Server identity comes from the Viewport Source.                                                       |
| `scrollToIndex` as the final Cell reveal algorithm in [`data-grid-table-virtual.tsx`](https://github.com/keenthemes/reui/blob/14185b983e9049ac6786e0f69a764bb3ba70a2b5/registry-reui/bases/base/reui/data-grid/data-grid-table-virtual.tsx)                  | It may help mount a distant destination, but BrunoTable must finish with its own minimum-delta reveal after sticky-header and effective pinned insets.                         |
| `clearSorting()` and an unsorted cycle from [`data-grid-column-header.tsx`](https://github.com/keenthemes/reui/blob/14185b983e9049ac6786e0f69a764bb3ba70a2b5/registry-reui/bases/base/reui/data-grid/data-grid-column-header.tsx)                            | Every BrunoTable always retains one through all sortable columns. The last active sort cannot be removed.                                                                      |
| Mapping zero selected facet values to `undefined` in [`data-grid-column-filter.tsx`](https://github.com/keenthemes/reui/blob/14185b983e9049ac6786e0f69a764bb3ba70a2b5/registry-reui/bases/base/reui/data-grid/data-grid-column-filter.tsx)                   | BrunoTable Clear All stores explicit empty inclusion intent and compiles Match None for current and future values.                                                             |
| Generic destructive CRUD/delete and ordinary success/error toast behavior from [`c-data-grid-22.tsx`](https://github.com/keenthemes/reui/blob/14185b983e9049ac6786e0f69a764bb3ba70a2b5/registry-reui/bases/base/components/data-grid/c-data-grid-22.tsx)     | Editable BrunoTable uses typed validation, atomic Save Change Sets, live reconciliation, Conflict Review, persistent accessible failure notifications, and no delete command.  |
| Treating table-wide aggregate footers as grouped results                                                                                                                                                                                                     | BrunoTable V1 Aggregate Cells belong to flat grouped-summary rows and preserve originating Column Identity. A table-wide summary footer would be a separate future capability. |

Do not move ReUI requirements into issues #7, #12, #17, #20, #21, #22, or #23. Issue #7 is an active foundational slice; ReUI does not model BrunoTable's exact typed filters or View Server translation; its aggregate footers are not grouped Aggregate Cells; and its CRUD workflow does not meet BrunoTable's editing-safety contract.
