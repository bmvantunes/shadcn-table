# Reconcile void save operations through the live source

`onSaveEdits` accepts one non-empty atomic row-grouped Save Change Set and returns only `PromiseLike<void>`; it never returns canonical rows, Row Versions, conflicts, or a result discriminant. Save preflight safely rebases each row only after every edited field still equals its Base, while the live Client Source remains the sole canonical outcome authority and reconciles timeout-free Accepted Overlays after Promise resolution. This avoids duplicating the read model in write responses: Immediate mode deliberately trades occasional same-row compare-and-set rejection for concurrent cell-scoped editing, while Batch globally locks edit mutations through complete live reconciliation to preserve coordinated transaction intent.
